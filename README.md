# Medicine Sales Data Analysis Dashboard

An interactive data analytics project based on medicine sales data. This project uses an Excel dataset to analyze sales performance, revenue trends, product demand, and business insights through a dashboard.

## Project Overview

The objective of this project is to transform raw medicine-sales data into meaningful business insights. The dashboard helps users understand sales performance and identify trends related to medicines, time periods.

This project demonstrates the complete data-analysis process:

- Importing data from an Excel file.
- Understanding and preparing the dataset.
- Analyzing sales and revenue information.
- Creating charts and key performance indicators.
- Presenting insights through an interactive dashboard.
- Supporting data-driven business decisions.

## Dataset

The project uses the file [`Sales data of medicines.xlsx`](./Sales%20data%20of%20medicines.xlsx) as the primary data source.

The dataset can be used to study information such as:

- Medicine names and product details.
- Sales amount and revenue.
- Sales dates and time-based trends.


The exact fields depend on the columns available in the Excel workbook.

## Key Analysis products

The dashboard is designed to provide insights into the following products:

### 1. Overall Sales Performance

The dashboard can be used to monitor total sales, and other important performance indicators.

### 2. Medicine-Wise Analysis

Medicine-level analysis helps identify:

- Best-selling medicines.
- Low-performing products.
- Products contributing the most revenue.
- Differences in demand between medicines.

### 3. Category Analysis

Grouping medicines by category makes it easier to compare product groups and determine which categories generate the highest sales.

### 4. Time-Based Trends

Sales can be analyzed across different time periods to identify:

- Yearly sales trends.
- Periods with high or low revenue.
- Growth or decline in sales performance.

### 5. Business Insights

The dashboard supports business decisions by helping users:

- Identify high-demand medicines.
- Improve inventory planning.
- Compare product performance.
- Detect changes in customer demand.
- Focus on profitable products and categories.

## How to Use This Project

1. Download or clone this repository.

   ```bash
   git clone https://github.com/Ankitnauhwar/Data-analytics-.git
   ```

2. Open [`Sales data of medicines.xlsx`](./Sales%20data%20of%20medicines.xlsx) in Microsoft Excel.

3. Review the source data and available worksheets.

4. Use the dashboard, pivot tables, filters, and charts to explore the sales information.

5. Compare medicines, categories, time periods, and other available dimensions.
